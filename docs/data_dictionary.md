# Data dictionary

All data are **synthetic** and generated by `src/generate_data.py`.

## matches.csv

| Column | Description |
|---|---|
| match_id | Unique match identifier |
| match_datetime | Match start timestamp |
| duration_min | Match duration in minutes |
| surrendered | Whether the match ended via surrender |
| team_a_avg_mmr | Average MMR of team A |
| team_b_avg_mmr | Average MMR of team B |
| team_a_win | Team A outcome: 1 win / 0 loss |
| patch | Fictional patch label |

## match_participants.csv

One row per player per match (10 rows per match).

Core fields include team, role, champion, win, kills, deaths, assists, CS, vision, wards, damage, gold, objective participation, first blood and lane advantage.

## players.csv

One row per account with region, tier, current MMR, primary role, play style and account age/activity attributes.

## champions.csv

Champion reference table containing class, primary role, synthetic baseline pick/ban assumptions and difficulty score.

## match_objectives.csv

Match-level objective totals for each team: dragons, barons and towers.
